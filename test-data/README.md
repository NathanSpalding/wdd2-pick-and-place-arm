# Test data

The test numbers in the file names (8.2 to 8.8) come from the project proposal. They map to the report as follows:

| Data | Report section | Test |
|---|---|---|
| bring-up, 9 Oct | 3.5.4 | Servo calibration fits and gripper positions |
| 8.2 | 4.2 | Encoder calibration against a reference |
| 8.3 | 4.3 | Encoder noise and servo deadband |
| 8.4 | 4.4 | Loop rate and step response, trim on and off |
| 8.5 | 4.5 | Grasp detection, 50 to 500 g |
| 8.6 | 4.6 | Positioning accuracy and repeatability |
| 8.7 | 4.7 | Pick-and-place cycles |
| 8.8 | 4.8 | Full-extension hold, rail voltages, temperatures, emergency stop |
| 20 Oct | 4.7, 4.9 | Waypoint-mode cycle with v2.5 firmware |

Each day folder has its notes (`WDD2_testing_day*.md`), the test log (`WDD2_Test_Log.xlsx`), processed CSV files and the raw serial logs or GUI exports.
